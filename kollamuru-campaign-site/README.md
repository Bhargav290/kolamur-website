# Kolamuru community information website

A responsive static website with Telugu/English toggle and the supplied campaign banner.

## Preview locally
Open `index.html` in a browser.

## Deploy
Upload the contents of this folder (`index.html` and `assets/`) to your static hosting provider's public web root.

## Important
- The contact form is demo-only and does not transmit or store submissions.
- The voter-services button links to the Election Commission of India's official portal.
- This is a community information page, not an official government website.
- No third-party voter database or private voter lookup API is integrated.
- Replace placeholder community updates and confirm all public claims before publishing.
